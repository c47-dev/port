# Clarify

## Purpose

Use this phase when user information is not enough to plan safely.

## Required Actions

- identify missing intent, boundaries, non-goals, or decision ownership
- determine whether more user information is needed
- use `deep-interview` when intent, boundaries, non-goals, or decision ownership are unclear
- stop when the request is materially branching and cannot be resolved from repository facts

## Required Output

1. clarified intent or the minimum blocking question
2. confirmed boundary, if any
3. whether planning can start

## Stop Rule

Stop here if the request is still ambiguous in a materially branching way.
